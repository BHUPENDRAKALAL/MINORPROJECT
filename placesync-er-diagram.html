Overview

The main path: a company runs a drive, a student takes part, rounds record attendance and results, and the drive ends in an offer and a placement record.

  • sha256 on every file finds the same marksheet uploaded by two students.

  • ReviewTask is the shared work queue. branch/batch/studentId on the task let the system skip a volunteer's own batch.

  • Private notes and student-facing feedback are separate tables, so a note can never leak to a student by mistake.
